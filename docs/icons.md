# Marketplace icons

Generated with the built-in image generation tool on 6 October 2026.
The character reference is [the canonical Meatsack workshop illustration](https://github.com/garylesueur/meatsack-brand/blob/main/assets/reference/ask-workshop.jpg), following the [character guide](https://github.com/garylesueur/meatsack-brand/blob/main/docs/characters.md).

Source assets live in each product repository at `public/plugin-icon.png`.
The marketplace copies them through its normal allowlist and sync workflow.
These are plugin listing icons; the existing website logos remain separate.
All three plugin manifests were advanced to version `0.1.1`.

## Prompt set

Ask: Create one square marketplace icon using the reference cream cloth Meatsack character: pear-shaped off-white sack, gathered top tied with olive cord, dark oval eyes, friendly smile, olive limbs, and kelp steak-cut belly emblem. Center the full standing character slightly up and left on a warm cream background. Preserve the handmade editorial screen-print style, imperfect charcoal outlines, flat muted fills, and sparse ink texture. Overlay a circular rust question-mark badge at the bottom right, about 30% of the square width. Keep the face and belly emblem visible and retain safe margins. No words, scenery, extra characters, gradients, 3D, or gore.

Show: Use the generated Ask icon as the edit target. Change only the bottom-right badge to muted kelp green and replace the question mark with a bold cream presentation-screen glyph containing a landscape triangle and sun, with a short stand. Preserve the character, background, pose, outline, texture, dimensions, and badge position and size.

Share: Use the generated Ask icon as the edit target. Preserve the character, background, pose, outline, texture, dimensions, and badge position and size.
